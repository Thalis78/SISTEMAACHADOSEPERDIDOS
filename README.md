# 🗂 Sistema de Achados e Perdidos

Este repositório contém o projeto do **Sistema de Achados e Perdidos**, desenvolvido com o objetivo de otimizar o controle e a devolução de documentos perdidos no **IFPI**. A aplicação foi projetada para facilitar o gerenciamento de itens perdidos, tornando o processo de devolução mais ágil e organizado.

A solução conta com um backend robusto utilizando **Spring Boot** e um banco de dados **PostgreSQL**, enquanto o frontend é construído com **HTML**, **CSS** e **JavaScript** puro, garantindo uma interface simples e funcional.

---

## 🧩 Tecnologias Utilizadas

- **Backend**:
  - **Spring Boot** – Framework Java para desenvolvimento rápido de aplicações web.
  - **PostgreSQL** – Banco de dados relacional para armazenamento de dados.
  - **Thymeleaf** – Template engine para renderização dinâmica de páginas HTML no lado do servidor.

- **Frontend**:
  - **HTML5** – Estruturação da página e conteúdo.
  - **CSS3** – Estilização e design da interface.
  - **JavaScript** – Interatividade e manipulação de dados no frontend.

---

## 🖥 Funcionalidades

- **Cadastro de Itens Perdidos**: Permite registrar itens perdidos, com informações como descrição, categoria e data.
- **Busca e Filtro**: Usuários podem buscar itens por diferentes critérios (ex: categoria, local, data).
- **Registro de Devoluções**: Permite registrar a devolução de itens encontrados ao dono.
- **Interface Responsiva**: Layout adaptável para diferentes tamanhos de tela (desktop, tablet, celular).
